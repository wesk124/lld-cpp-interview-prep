# Connect Four: Core Test Checklist

- [ ] Gravity; full/out-of-range columns; unchanged turn on failure.
- [ ] Horizontal, vertical and diagonal wins; terminal rejection; draw.
- [ ] A connect-three rule changes the outcome without modifying Game.
- [ ] Name the pattern participants and verify polymorphic behavior where relevant.

The checklist matches the small base contract. Follow-up features have separate design discussions rather than extra base-test requirements.
